# WK DocOps

A Python toolkit for documentation reliability.

## Purpose

WK DocOps validates documentation ownership,
review metadata, local links, and technical claims.

## Getting started

Install the package:

    python -m pip install -e .

Run the scanner:

    wkdocops docs

## Documentation governance

Every document must have an owner and a review date.
